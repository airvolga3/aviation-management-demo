# Авиагруппа · Управленческие экраны

Публичная демонстрация пирамиды управления: владелец → управляющая компания → компании → показатели → рейсы, отправки и основания.

Все названия условные, данные синтетические. Это не отчётность какой-либо организации. Названия, сотрудники и контрагенты не обозначают реальные юридические или физические лица. Демонстрация не подключается к корпоративным системам.

## Состав

- Авиакомпания 1 — чартерная модель.
- Авиакомпания 2 — регулярная и чартерная модель.
- Авиакомпания 3 — преимущественно регулярная модель.
- Технические центры 1–2, инжиниринговая, лизинговая и страховая компании.
- Общие финансовые показатели, план/факт/прогноз, графики, раскрытия, справочник показателей и две темы.

Начните с обзора группы, затем откройте компанию. В коммерции авиакомпаний 2 и 3 доступна история одного регулярного вылета: бронирования → приёмка → погрузка → результат. Сервисные компании пока представлены общим обзором, не полным отраслевым продуктом.

## Запуск и публикация

Требуется Node.js 22.13 или новее. `npm ci`, затем `npm run dev` для локального просмотра. `npm run build` формирует автономный сайт в `docs/`. `npm run check` проверяет связность и безопасность публичного пакета.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → /docs → Save. Относительные пути позволяют размещать сайт в подкаталоге репозитория; переходы между экранами используют hash-маршруты.

Сайт не требует API, сервера приложений или ключей. Все данные загружаются из JSON рядом с сайтом. Настройка `noindex` — рекомендация поисковым роботам, не ограничение доступа: посетитель может скачать опубликованные данные и код.

## Границы

План и прогноз различаются; отсутствие данных не заменяется нулём. История двух регулярных вылетов реконструирована под итог примера и не доказывает точность прогнозирования спроса. Расчёты не являются разрешением на вылет, сертифицированным расчётом загрузки или утверждённой учётной политикой. Источники методики открываются через справки.

Публичная версия содержит только демонстрационную клиентскую часть и синтетические наборы. Она не включает корпоративные адаптеры, ключи, закрытую документацию и прежнюю историю разработки.

Полный учебный набор хранится в fixtures/executive.json; scripts/prepare-data.mjs формирует профили для public/data/ перед сборкой. Проверки: npm run check, npm run check:regressions, npm run build. Регрессии проверяют рендеринг целевых экранов и сверку сценариев. Полная повторная визуальная приёмка всех экранов не выполнялась.

CSP в HTML ограничивает источники ресурсов; inline-скрипты и стили пока разрешены. Это не nonce-based CSP. frame-ancestors требует серверного заголовка, который стандартный GitHub Pages не предоставляет.
